# Seasons

Each folder holds one season's `season.json`: extra items, colors, patterns and house notes that show up while the season is on. Dates are in `config/seasons.json`.

- **fall**: pumpkin color, leafy pattern, witch hat, pumpkin sweater and costume cape.
- **winter**, **spring**, **summer**: empty folders with a README, waiting for someone to build them. See [docs/add-a-season.md](../docs/add-a-season.md).
