# Winter

This season is empty and waiting for someone to build it. It's a good first issue.

1. Copy `../fall/season.json` into this folder and change it: the name, an accent color, any items, colors, patterns and house notes.
2. Delete this README.
3. Run `npm run check` and `npm test`.

The full guide is [docs/add-a-season.md](../../docs/add-a-season.md). The dates this season runs are in `config/seasons.json`.
