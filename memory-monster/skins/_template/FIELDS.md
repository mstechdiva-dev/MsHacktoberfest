# Skin template

Copy this whole folder, rename it, and edit `skin.json`. Folders that start with an underscore are not loaded, so this one never appears in the Figure list.

Every field is optional. The full list of fields and allowed values is in MAKE-YOUR-OWN-FIGURE.md.

- `face.style`: void, skull, mask, grin, pumpkin
- `door.style`: wood, metal, curtain, portal
- `door.opens`: swing, slide
- `entrance.style`: walk-out, rise, slide, drop
- Colors look like `#38bdf8`
